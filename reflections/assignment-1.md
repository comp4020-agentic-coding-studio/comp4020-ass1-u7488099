# Assignment 1 Reflection

## What was the breakthrough?

My biggest breakthrough was realising that passing tests and having the agent tell me something was correct did not necessarily mean the product was actually good. This happened several times during the assignment. For example, the first piano-roll editor passed the automated browser tests, but when I opened it myself I could not actually see the notes I was placing. Later, the synthesised instruments were technically working and different styles produced different sounds, but when I listened to them they simply sounded bad. The same thing happened with some of the musical transformations, where the output was mathematically valid but sounded unnatural.

This changed how I worked with Claude. Instead of treating a green test suite as the end of a task, I started using it as one type of evidence. I would then manually use the website, listen to the music, and challenge results that did not feel right.

## What did this change about the developer I want to be?

This project made me want to be a developer who uses agents heavily without giving up judgement to them. Claude was extremely useful for implementing, testing and investigating problems quickly, but I found that I still needed to decide whether its solution actually solved the problem I cared about. In future projects, I want to spend less time telling an agent exactly what code to write and more time defining the goal, testing the result critically, and knowing when to reject a technically correct solution because the actual user experience is poor.
